# Contributing

Thanks for wanting to help. This project has a clear purpose: **artists owning their work, end to end, on their own
machines**. Contributions that serve that are welcome.

## Before you start
- **Bugs:** open an issue with the bug template: what you did, what you expected, what happened, your OS, and the
  network (testnet/mainnet). Never paste a seed phrase, private key or Pinata key.
- **Ideas:** open an issue first and describe the problem it solves. Big changes are easier to agree on before the code exists.
- **Security holes:** don't open an issue; see [SECURITY.md](SECURITY.md).

## What gets accepted
- ✅ Fixes, clearer wording, better guides, translations, accessibility, tests.
- ✅ Features that keep the user sovereign: local-first, their own storage, their own wallet.
- ❌ Anything that makes the app handle private keys or seed phrases.
- ❌ Accounts, tracking, analytics, telemetry, or phoning home.
- ❌ Required third-party services (optional ones, like Pinata, are fine if the self-hosted path still works).
- ❌ New runtime dependencies for the server. It's Python standard library only, so anyone can run it.

## How to send a change
1. Fork, then make a branch: `git checkout -b fix-short-description`.
2. Keep the style of the surrounding code. The server is one `server.py`; pages live in `web/` with no inline scripts (the CSP forbids them).
3. Run the offline self-test: `python3 tools/selftest.py` (CI runs it too). Then test by hand: run `python3 server.py`, go through setup, build a small collection, and, if you touched the contract or the
   mint page, **deploy and mint it on testnet**.
4. Open a pull request that says what changed, why, and how you tested it.

## Contract changes
The contract is generated by `build_contract()` in `server.py`. It must stay **plain ASCII** (the network rejects
anything else), and every change needs a testnet run of deploy → mint → set-base-uri → refresh-metadata → freeze → a
refused set-base-uri after freezing, plus a mint beyond the maximum supply (must fail with `err u104`).

## The wallet bundle
`web/stacks.js` is generated, never edited by hand. To change the Stacks libraries, bump the versions in
`tools/wallet-bundle/package.json` and its lockfile, then run `bash tools/wallet-bundle/build.sh --write` and commit
both the bundle and `web/stacks.js.sha256`. CI rebuilds it and fails on any difference.
